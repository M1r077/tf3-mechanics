城镇只靠**你的**运输增长：乘坐你的线路到达的乘客，以及交付到城镇建筑的货物，会给城镇带来经验（XP）。城镇的评价决定这些经验有多少能算数，每升一级城镇都会变大。

```diagram town_xp
```

## 经验从哪里来

| 来源 | 原始经验 | 来源文件 |
|---|---|---|
| 乘客**乘坐你的线路**到达城镇建筑 | 5 · 10 · 20：住所与工作地点或购物地点在同一城镇、在邻近城镇、在更远的城镇 | `town_growth.script.tl:649-701`，`town_growth_config.res.lua:6` |
| 交付到城镇建筑的一个货物单位 | 货物等级 0 · 1 · 2 分别为 10 · 20 · 40 | `town_growth.script.tl:642`，`town_growth_config.res.lua:5` |
| 补贴奖励“城镇经验” | 当前等级的一定比例，同样 × 增长率 | `subvention_util.tl:144-152`，`town_growth.script.tl:608` |

- 经验归乘客或货物**到达**的建筑所在的城镇。在两个城镇之间通勤的人会给两个城镇都带来经验：去程给工作地点所在的城镇，回程给住所所在的城镇。
- 往返**产业**的行程不带来经验（`town_growth.script.tl:680-683`）。步行或开车的行程也不带来经验：只有乘坐你的线路的行程才算（`town_growth.script.tl:656`）。
- 单靠时间流逝什么也得不到：每个 tick 的经验为 0（`town_cargo_util.tl:6`）。
- 货物等级：**0** 砖石、水泥、鱼、燃料、肉类、厚木板、蔬菜；**1** 饮料、书籍、衣物、家具、机器、罐头食品、工具；**2** 载具（`placementparamsutil.lua:506-616`）。

每份原始经验都要乘以城镇的**增长率**（`town_growth.script.tl:60-63`）。城镇窗口中显示为 **增长率：**。

## 增长率

增长率来自城镇窗口中的两项评价（`town_util.tl:607-633`，`town_util.tl:954-962`）：

1. **城镇当局**：六项评价中**最低**的一项，而不是平均值（`town_util.tl:754-784`）。
2. **供应**：乘客和货物两项供应水平的平均值，向上取整（`town_util.tl:555-589`）。

```diagram growth_matrix
```

- 每项评价分六档：0–1 的数值按六分之一切分（`town_util.tl:983-985`）。**极佳** 需要 5/6 = 83 % 或更高。
- 只要有**一项**评价为非常贫穷，当局评价就是非常贫穷，增长率为 **0 %**：无论你交付什么，城镇都停止增长。
- 要达到 100 %，需要当局为极佳且供应至少为非常好，或者当局为非常好且供应为极佳。
- 你的**总部**会给离它最近的城镇 +5 %，若干扩建各加 +5 %，有些更少或没有；数值写在每个模块的文件里（`headquarter.script.tl:510-515`，`landmark_util.tl:51-70`）。这个加成是乘在增长率上的，所以在 0 % 时没有任何作用。

```tip scripts
**城镇不再增长？先修好最差的那项评价。** 城镇当局是六项评价中最低的一项：只要有一项非常贫穷，增长率就停在 0 %，改善其他评价也没用。
```

## 六项当局评价

| 评价 | 什么会降低它 | 来源 |
|---|---|---|
| **声誉** | 地形改造、拆除城镇建筑、移除树木或岩石、补贴失败；每切断一条通往其他城镇的主要连接 −1/3 | `town_util.tl:396-404`，`town_util.tl:1608`，`town_react_util.tl:30-43` |
| **交通** | 城镇内道路拥堵 | `town_util.tl:445-456` |
| **幸福感** | 不满意的出行者所占比例（至少按 15 人计算） | `town_util.tl:479-503` |
| **运送** | 迟到的货物交付所占比例（见 [货物收入](income.html)） | `town_util.tl:505-519` |
| **噪音** | 城镇噪音：65 dB 或更低 → 满分，80 dB → 0 | `town_util.tl:433-443`，`emission_config.tl:10-11` |
| **污染** | 城镇区域每个 16 m 格子的平均污染，按脚本的对数刻度（“dB”，不是声音大小）：60 → 满分，74 → 0 | `town_util.tl:413-431`，`emission_config.tl:23-24` |

**敏感度**设置会移动这些界限：声誉只有关闭 / 打开两档，其余五项从关到极高共七档，正常为 ×1（噪音和污染的上限更高：最高 ×3.5 和 ×5，其余为 ×3）；关表示始终满分（`difficulty_util.tl:44-49`）。

## 供应

- **乘客**：城镇的线路使用率 × 2，所以 **50 % 的线路使用率就能得到满分**（`town_util.tl:546-553`）。
- **货物**：每个区（住宅区、商业区、工业区）所有货物合计的供应 ÷ 需求；取**最好**的那个区，而不是平均值（`town_util.tl:521-543`）。
- 没有任何需要供应的城镇算作供应满分。既没有从你这里得到乘客、也没有得到货物的城镇算作“没有交付”：增长率 0 %（`town_util.tl:565-588`）。

```tip scripts
**不需要让所有居民都坐你的线路：50 % 的线路使用率就已经是满分的乘客评价。**
```

新的货物需求随等级出现（`placementparamsutil.lua:618-660`）：开始时有一个商业需求和一个工业需求，5 级时出现第二个商业需求，7 级时第二个工业需求，9 级时第三个商业需求，11 级时第三个工业需求。只有在城镇至少收到过一次货物交付之后，这些需求才会加入（`town_growth.script.tl:286-288`）。游戏会优先选择其他城镇很少需要的货物（`town_growth.script.tl:258-266`）。

## 等级与规模

- 升到 2 级需要 1,000 经验，之后每一级都是前一级的 1.5 倍（`town_cargo_util.tl:81-97`，`town_growth_config.res.lua:7`）：5 级累计 8,125 经验，10 级约 75,000，18 级（大型都会，最后一级）约 200 万。
- 放置时住宅较多的城镇起始等级更高：2、3 或 4 级（`town_cargo_util.tl:43-54`）。
- **目标规模** 取决于开局以来升了多少级，包括向下一级的进度（`town_cargo_util.tl:100-110`，`town_growth_function.tl:4-11`）：

```diagram town_size
```

- 新增的规模按服务好坏分配给居民区、商业区和工业区：居民区看乘客使用情况，其他两区看货物供应（`town_growth.script.tl:404-421`）。一个区占到城镇的 40 % 后，它能拿到的新增规模上限会从 100 % 逐渐降到 50 %，直到它占城镇的 50 %（整张地图也有类似的限制）（`town_growth.script.tl:509-522`）。如果没有任何一个区得到服务，即使有经验城镇也不会增长（`town_growth.script.tl:415`）。

```engine
线路使用率、交通速度、噪音和污染分布图、迟到交付的列表都由引擎计算，新的房屋和街道也由引擎建造。一个区始终能得到的最小份额（townGrowthMinDistrictFraction）是引擎中的数值。
```

## 货物需求与建筑库存

- 城镇的需求是它所有**建筑**的总和。每座建筑对其所在区需要的每种货物都有一个小的输入库存：容量 ÷ 4，向上取整，再 × 该货物在城镇需求中的系数（未另行设定时为 1；系数来源不在脚本中）（`townbuildingutil.lua:226-251`）。每种货物都定义了 townConsumptionFactor，为 1、0.5 或 0.25（`placementparamsutil.lua:506-616`）；它如何传到建筑由引擎决定。游戏代码注明这个库存大小“is currently nowhere shown in the UI”（`townbuildingutil.lua:249`）。
- 城镇窗口中的需求是这些库存上限的总和；评价中计入的供应以需求为上限（`town_util.tl:95-99`，`town_util.tl:194-198`）。城镇越大建筑越多，需要的也越多。
- 建筑窗口显示**消费评级**：建筑使用货物的速度与其最大值相比（`town_building.tl:103-132`）。
- 一个单位进入建筑库存时，才获得经验和货款（`town_growth.script.tl:620-642`）。
- 站点只能覆盖其服务范围内的建筑。即使整个城镇仍有缺口，这些建筑的库存也可能已满：这时放不下的货物**留在载具上**，除非勾选了**到达时强制卸下所有货品**（“在库存已满的情况下仍然卸货。”）（`cargofilter_window.tl:757-763`），这会销毁放不下的部分（见[装载与卸载速度](loading.html)）。
- 留在车上的货物会触发通知**卸货问题**：“{vehicle}的{cargoCount}单位货物没有在该线路上卸货”（`cargo_rtc_warning.script.tl:28-41`，`cargo_rtc_warning.script.tl:37`）；其类型标签为**货物未卸下**（`cargo_rtc_warning.res.lua:6`）。
- **城镇货物需求**（“选择每个城镇的最大商品需求量”）：2、4 或 6，默认 2（`difficulty_util.tl:54`，`difficulty_util.tl:83`，`mod.script.tl:173`，`mod.script.tl:205`）。脚本按等级添加需求（见上文），并把这个值传给引擎。

```engine
建筑消耗库存的速度（consumeFrequency）、服务范围内哪座建筑得到每个单位、被来回运送的货物会怎样，以及引擎如何使用城镇货物需求，都在引擎端。
```

## 能阻止城镇增长吗？

- 在普通游戏中，**没有设置**可以限制城镇最大规模（`difficulty_util.tl:90-199`）。
- 在**沙盒模式**中，城镇窗口有一张**目标区域容量**卡片，其中有**启用城镇发展**（`town_eow.script.tl:1041-1052`，`town_eow.script.tl:1170-1171`，`town_eow_editor_initial_capacity.res.lua:6`）。取消勾选后，城镇不获得经验，也不改变规模；窗口显示**城镇发展未激活**（`town_growth.script.tl:28`，`town_growth.script.tl:345`，`town_eow.script.tl:107`）。
- 没有沙盒时，只有间接的办法：城镇只靠你的乘客和货物增长，只要有一项评价为非常贫穷就会停止（见上文）。

## 须知

- **先解决最差的那项评价**：当局评价取最低值，提高其他评价没有用。
- **两个城镇之间**的乘客带来的经验是城镇内部行程的 2 倍（邻近城镇）或 4 倍（更远），而且两个城镇都能得到。
- 商业货物只有 0–1 级；只有**载具**（工业）每单位给 40 经验，而城镇通常要到第三个工业需求（11 级）才会需要它。
- 离你的总部较远的城镇得不到加成：只有最近的那个城镇能得到。
