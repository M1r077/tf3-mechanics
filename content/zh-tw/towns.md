城鎮只靠**你的**運輸成長：搭乘你的路線抵達的乘客，以及配送到城鎮建築的貨物，會為城鎮帶來經驗值（XP）。城鎮的評價決定這些經驗值有多少能算數，每升一級城鎮都會變大。

```diagram town_xp
```

## 經驗值從哪裡來

| 來源 | 原始經驗值 | 來源檔案 |
|---|---|---|
| 乘客**搭乘你的路線**抵達城鎮建築 | 5 · 10 · 20：住處與工作地點或購物地點在同一城鎮、在鄰近城鎮、在更遠的城鎮 | `town_growth.script.tl:649-701`，`town_growth_config.res.lua:6` |
| 配送到城鎮建築的一單位貨物 | 貨物階級 0 · 1 · 2 分別為 10 · 20 · 40 | `town_growth.script.tl:642`，`town_growth_config.res.lua:5` |
| 補助獎勵「城鎮經驗值」 | 目前等級的一定比例，同樣 × 成長率 | `subvention_util.tl:144-152`，`town_growth.script.tl:608` |

- 經驗值歸給乘客或貨物**抵達**的建築所在的城鎮。在兩個城鎮之間通勤的人會讓兩個城鎮都獲得經驗值：去程給工作地點所在的城鎮，回程給住處所在的城鎮。
- 往返**產業**的行程不會帶來經驗值（`town_growth.script.tl:680-683`）。步行或開車的行程也沒有：只有搭乘你的路線的行程才算（`town_growth.script.tl:656`）。
- 單靠時間流逝什麼也得不到：每個 tick 的經驗值為 0（`town_cargo_util.tl:6`）。
- 貨物階級：**0** 磚塊、水泥、漁獲、燃料、肉品、木板、蔬菜；**1** 飲料、書籍、衣物、家具、機械、罐頭食品、工具；**2** 車輛（`placementparamsutil.lua:506-616`）。

每份原始經驗值都要乘上城鎮的**成長率**（`town_growth.script.tl:60-63`）。城鎮視窗中顯示為 **成長率：**。

## 成長率

成長率來自城鎮視窗中的兩項評價（`town_util.tl:607-633`，`town_util.tl:954-962`）：

1. **城鎮管理機關**：六項評價中**最低**的一項，而不是平均值（`town_util.tl:754-784`）。
2. **供應**：乘客與貨物兩項供應程度的平均值，無條件進位（`town_util.tl:555-589`）。

```diagram growth_matrix
```

- 每項評價分為六級：0–1 的數值以六分之一切分（`town_util.tl:983-985`）。**卓越** 需要 5/6 = 83 % 以上。
- 只要有**一項**評價為極差，管理機關評價就是極差，成長率為 **0 %**：無論你配送什麼，城鎮都會停止成長。
- 要達到 100 %，需要管理機關為卓越且供應至少為極佳，或管理機關為極佳且供應為卓越。
- 你的**總部**會讓距離它最近的城鎮 +5 %，它的大多數擴建再各加 +5 %（`headquarter.script.tl:510-515`，`landmark_util.tl:51-70`）。這個加成是乘在成長率上的，所以在 0 % 時毫無作用。

```tip scripts
**城鎮不再成長？先修好最差的那項評價。** 城鎮管理機關是六項評價中最低的一項：只要有一項極差，成長率就停在 0 %，改善其他評價也沒用。
```

## 六項管理機關評價

| 評價 | 什麼會降低它 | 來源 |
|---|---|---|
| **聲望** | 地形改造、拆除城鎮建築、移除樹木；每切斷一條通往其他城鎮的主要連線 −1/3 | `town_util.tl:396-404`，`town_util.tl:1608` |
| **交通** | 城鎮內道路壅塞 | `town_util.tl:445-456` |
| **快樂度** | 不滿意的旅客所占比例（至少以 15 人計算） | `town_util.tl:479-503` |
| **配送** | 遲到的貨物配送所占比例（見 [貨運收益](income.html)） | `town_util.tl:505-519` |
| **噪音** | 城鎮噪音：65 dB 以下 → 滿分，80 dB → 0 | `town_util.tl:433-443`，`emission_config.tl:10-11` |
| **汙染** | 城鎮區域每個 16 m 格子的平均汙染，按腳本的對數刻度（「dB」，不是聲音大小）：60 → 滿分，74 → 0 | `town_util.tl:413-431`，`emission_config.tl:23-24` |

**靈敏度**設定會移動這些界限：聲望只有關閉 / 開啟兩段，其餘五項從關閉到極限共七段，普通為 ×1（噪音和污染的上限更高：最高 ×3.5 和 ×5，其餘為 ×3）；關閉代表始終滿分（`difficulty_util.tl:44-49`）。

## 供應

- **乘客**：城鎮的路線使用量 × 2，所以 **50 % 的路線使用量就能拿到滿分**（`town_util.tl:546-553`）。
- **貨物**：每個區域（住宅區、商業區、工業區）所有貨物合計的供應 ÷ 需求；取**最好**的那個區域，而不是平均值（`town_util.tl:521-543`）。
- 沒有任何需要供應項目的城鎮算作供應滿分。既沒有從你這裡得到乘客、也沒有得到貨物的城鎮算作「沒有配送」：成長率 0 %（`town_util.tl:565-588`）。

```tip scripts
**不需要讓所有居民都搭你的路線：50 % 的路線使用率就已經是滿分的乘客評價。**
```

新的貨物需求會隨等級出現（`placementparamsutil.lua:618-660`）：一開始有一個商業需求與一個工業需求，等級 5 出現第二個商業需求，等級 7 出現第二個工業需求，等級 9 出現第三個商業需求，等級 11 出現第三個工業需求。只有在城鎮至少收到過一次貨物配送之後，這些需求才會加入（`town_growth.script.tl:286-288`）。遊戲會優先挑選其他城鎮較少需要的貨物（`town_growth.script.tl:258-266`）。

## 等級與規模

- 升到等級 2 需要 1,000 經驗值，之後每一級都是前一級的 1.5 倍（`town_cargo_util.tl:81-97`，`town_growth_config.res.lua:7`）：等級 5 累計 8,125 經驗值，等級 10 約 75,000，等級 18（大型都會，最後一級）約 200 萬。
- 放置時住宅較多的城鎮起始等級較高：等級 2、3 或 4（`town_cargo_util.tl:43-54`）。
- **目標規模** 取決於開局以來升了多少級，包括往下一級的進度（`town_cargo_util.tl:100-110`，`town_growth_function.tl:4-11`）：

```diagram town_size
```

- 新增的規模會依服務好壞分配給住宅區、商業區與工業區：住宅區看乘客使用情況，另外兩區看貨物供應（`town_growth.script.tl:404-421`）。一個區域占到城鎮的 40 % 後，它能拿到的新增規模上限會從 100 % 逐漸降到 50 %，直到它占城鎮的 50 %（整張地圖也有類似的限制）（`town_growth.script.tl:509-522`）。如果沒有任何一個區域獲得服務，即使有經驗值城鎮也不會成長（`town_growth.script.tl:415`）。

```engine
路線使用量、交通速度、噪音與汙染分布圖、遲到配送的清單都由引擎計算，新的房屋與街道也由引擎建造。一個區域始終能分到的最小份額（townGrowthMinDistrictFraction）是引擎中的數值。
```

## 貨物需求與建築庫存

- 城鎮的需求是它所有**建築**的總和。每棟建築對其所在區域需要的每種貨物都有一個小的輸入庫存：容量 ÷ 4，無條件進位，再 × 該貨物在城鎮需求中的係數（未另行設定時為 1；係數來源不在腳本中）（`townbuildingutil.lua:226-251`）。遊戲程式碼註明這個庫存大小「is currently nowhere shown in the UI」（`townbuildingutil.lua:249`）。
- 城鎮視窗中的需求是這些庫存上限的總和；評價中計入的供應以需求為上限（`town_util.tl:95-99`，`town_util.tl:194-198`）。城鎮越大建築越多，需要的也越多。
- 建築視窗顯示**消耗量評價**：建築使用貨物的速度與其最大值相比（`town_building.tl:103-132`）。
- 一個單位進入建築庫存時，才會獲得經驗值與貨款（`town_growth.script.tl:620-642`）。
- 站點只能涵蓋其服務範圍內的建築。即使整個城鎮仍有缺口，這些建築的庫存也可能已滿：這時放不下的貨物**留在車輛上**，除非勾選了**抵達時強制卸載所有貨物**（「即使庫存已滿仍卸載貨物。」）（`cargofilter_window.tl:757-763`），這會銷毀放不下的部分（見[裝載與卸貨速度](loading.html)）。
- 留在車上的貨物會觸發通知**貨物未卸載**：「{vehicle}上有{cargoCount}件貨物未在路線上卸載。」（`cargo_rtc_warning.res.lua:6`，`cargo_rtc_warning.script.tl:28-41`）。
- **城鎮貨物需求**（「選擇每個城鎮的貨物需求數量上限。」）：2、4 或 6，預設 2（`difficulty_util.tl:54`，`difficulty_util.tl:83`，`mod.script.tl:173`，`mod.script.tl:205`）。腳本依等級新增需求（見上文），並把這個值傳給引擎。

```engine
建築消耗庫存的速度（consumeFrequency）、服務範圍內哪棟建築得到每個單位、被來回運送的貨物會怎樣，以及引擎如何使用城鎮貨物需求，都在引擎端。
```

## 能阻止城鎮成長嗎？

- 在一般遊戲中，**沒有設定**可以限制城鎮最大規模（`difficulty_util.tl:90-199`）。
- 在**沙盒模式**與地圖編輯器中，城鎮視窗有一張**目標區域容量**卡片，其中有**啟用城鎮發展**（`town_eow.script.tl:1041-1052`，`town_eow.script.tl:1170-1171`，`town_eow_editor_initial_capacity.res.lua:6`）。取消勾選後，城鎮不會獲得經驗值，也不會改變規模；視窗顯示**未啟用城鎮發展**（`town_growth.script.tl:28`，`town_growth.script.tl:345`，`town_eow.script.tl:107`）。
- 沒有沙盒時，只有間接的辦法：城鎮只靠你的乘客與貨物成長，只要有一項評價為極差就會停止（見上文）。

## 小知識

- **先解決最差的那項評價**：管理機關評價取最低值，提高其他評價沒有用。
- **兩個城鎮之間**的乘客帶來的經驗值是城鎮內行程的 2 倍（鄰近城鎮）或 4 倍（更遠），而且兩個城鎮都能獲得。
- 商業貨物只有階級 0–1；只有**車輛**（工業）每單位給 40 經驗值，而城鎮通常要到第三個工業需求（等級 11）才會需要它。
- 距離你的總部較遠的城鎮拿不到加成：只有最近的那個城鎮能拿到。
