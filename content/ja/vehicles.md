どの車両にも固定の性能値（速度、容量、積載速度、価格、運行費、耐用年数）と、変化する 2 つの値、**状況**と**年数**がある。状況は走行中に下がり、整備で回復する。年数は増える一方である。

## 車両ストアの性能値

- ストアは各性能値をバーで表示する。バーは固定の目盛りではなく、同じ輸送手段・同じ時代の他の車両との比較である（`vehicle_util.tl:210-245`、`vehicle_util.tl:248-270`）。
- 列車の場合、ストアは全構成車両のうち**最も高い**積載速度を表示する（`vehicle_store_util.tl:333`）。
- ファイルで積載速度、騒音、汚染、快適性が設定されていない車両は、他の性能値（年、速度、出力、重量、大きさ）から計算された値を得る（`model_metadata_util.lua:395-417`、`vehicle_metadata_util.lua:233-256`）。計算された積載速度は 0.5 単位に丸められ、1 未満にはならない（`vehicle_metadata_util.lua:267-269`）。

## どの車両が最も速く積み込むか

車両の積載速度は最初の係数にすぎない。プラットフォームと在庫がそれに掛け合わされる（[積み込みと積み下ろしの速度](loading.html) を参照）。

| 輸送手段 | バー満杯で示される積載速度（最新の時代） | ソース |
|---|---|---|
| 船 | 10～45（2003 年から） | `vehicle_util.tl:219-223` |
| 道路車両、路面電車 | 0.5～10（1995 年から） | `vehicle_util.tl:232-243` |
| 列車 | 0.1～10（1981 年から） | `vehicle_util.tl:226-229` |
| 航空機 | 1～4（1978 年から） | `vehicle_util.tl:212-216` |

- 船の積載速度は群を抜いて高く、航空機の目盛りは最も低い。
- 同じ輸送手段の車両は、ストアの積載速度の列で比較すること。新しいモデルほどバーが高いことが多い。
- 貨物はすべて積載係数 0.0625、乗客は 1 である（`coal.cargo.lua:29`、`passengers.cargo.lua:23`）。

```engine
車両の積載速度、貨物の積載係数、プラットフォームと在庫の係数を組み合わせて実際の積載時間を出す計算はエンジンが行う。スクリプトは入力値を与えるだけである。
```

## 状況

| 状況 | 段階 | ソース |
|---|---|---|
| 80 % 超 | **優** | `vehicle_util.tl:159-172` |
| 60–80 % | **良** | `vehicle_util.tl:159-172` |
| 40–60 % | **可** | `vehicle_util.tl:159-172` |
| 20–40 % | **低い** | `vehicle_util.tl:159-172` |
| 20 % 以下 | **非常に低い** | `vehicle_util.tl:159-172` |

- 列車の状況は、すべての貨車と機関車の**平均**である（`vehicle_util.tl:285-295`）。
- 80 % を下回ると、車両は最高速度、出力、快適性を失い始め、騒音、汚染、運行費が増え始める（`vehicle_store_util.tl:230-259`）。車両ウィンドウはこれらのペナルティを**状況**の下に一覧表示する。
- これらのペナルティの強さは**車両整備エフェクト**（なし、低、中、高、非常に高）で決まる。なしでは状況は何の影響もない（`mod.script.tl:241-245`、`vehicle_store_util.tl:211-228`）。詳細：[コスト、維持費、融資](costs.html)。
- **20 %** 以下になると**車両状態**の警告が出る。警告は車両が **30 %** を超えるまで消えない（`notifications.script.tl:310-318`）。
- 複製した車両は新規購入となる。状況 100 %、新しい購入日（`manager_window.tl:8502-8506`）。

```engine
状況がどれだけ速く下がるか、整備ステーションへの訪問でどれだけ回復するか、各ペナルティの大きさ（getMaintenanceTopSpeedPenalty など）はエンジンの値である。各車両モデルは段階ごとに独自の最高速度ペナルティを設定することもできる（`vehicle_store_util.tl:250-253`）。
```

## 車庫と整備ステーション

車両は近くの車庫または整備ステーションで整備される。どちらも整備できる車両の数に限りがある。それが**整備プール**である。

| 建物 | 整備プール | ソース |
|---|---|---|
| 鉄道車庫 | 6 | `rail_depot.script.lua:349` |
| 鉄道整備ステーション | 12 | `rail_maint_station.script.lua:157` |
| 道路車庫、路面電車車庫 | 12 | `road_depot.script.lua:198`、`tram_depot.script.lua:226` |
| 道路整備ステーション | 16 | `road_maint_station.script.lua:240` |
| 船舶車庫 | 8 | `water_depot.script.lua:379` |
| 船舶整備ステーション | 12 | `water_maint_station.script.lua:262` |
| 飛行場または空港の格納庫 | 16 | `af_hangar.module.lua:280`、`ap_hangar.module.lua:463` |
| ヘリポート | 4 | `heliport.script.lua:309` |

- 建物ウィンドウには「使用中 / プール」（例：14 / 12）と、整備する車両の一覧がその状況とともに表示される（`entity_window_util.tl:2010-2039`、`maintenance_station_eow.script.tl:188-215`）。
- プールが埋まるほど建物は騒がしく汚くなる。排出はプールの使用率とともに増える（`emissions.script.tl:223-234`）。
- 鉄道整備ステーションは鉄道車庫の 2 倍の列車を整備する。12 対 6。
- 公式wikiは、車両に整備用の建物の前を通らせるためにウェイポイントを使うことを勧めている。

```engine
車両がどのステーションに割り当てられるか、プールを超える車両がステーションを使うとどうなるか、使われる集客半径は、エンジンが決める。
```

## 価格と運行費

- 基本ゲームの車両には固定価格がない。運行費は速度と容量から決まり、価格は運行費の **6 年分**である（`model_metadata_util.lua:548-549`）。計算式の全体：[コスト、維持費、融資](costs.html)。
- **車両コスト**と**車両整備**は、どちらも 50 % から 150 % まで調整される（`post_run_util.tl:54-81`）。
- 状況の悪い車両は、基本値に加えてより多くの運行費を払う（`vehicle_store_util.tl:256-259`）。

## 年数と耐用年数

- 各モデルには年単位の**耐用年数**がある（`vehicle_metadata_util.lua:79-83`）。路線ウィンドウの**年数**の列が年数を示し、そのツールチップに耐用年数の使用割合と残り時間、または**耐用期限に到達**が表示される（`line_eow.script.tl:133-147`）。
- 列車の場合、**最も古い**構成車両が基準になる（`vehicle_util.tl:36-52`）。古い貨車が 1 両あるだけで列車全体が古く表示される。

```engine
耐用年数に達すると何が変わるか（例えば状況の低下が速くなる、売却価格が下がるなど）はスクリプトにはない。スクリプトは年数と耐用年数を表示するだけである。
```

## 古い車両はいつ置き換えるべきか

1. 近くに整備ステーションがあっても**状況が低いまま**：車両は速度を失い、運行費が増える。まずステーションのプールを確認すること。満杯かもしれない。
2. 年数のツールチップに**耐用期限に到達**：モデルは予定の寿命を過ぎている。
3. **より良いモデルがある**：速い車両や大きい車両は運行費が高いが、より多く運ぶ（価格は速度 × 容量に従う）。
4. 路線マネージャーで**車両の置き換え**を使う。現在の車両との比較付きでストアが開く（`vehicle_store_window.tl:4893-4928`、`vehicle_store_window.tl:2611`）。

## 知っておくと便利なこと

- 十分な整備能力を建てること。鉄道車庫 1 つは 6 本の列車しか整備しない。
- **車両整備エフェクト**がなしなら、状況は関係ない。
- **車庫へ送る**は、車両を購入した車庫ではなく、到達できる最寄りの車庫へ送る（公式wiki）。
- [Vehicle Comparison](https://mod.io/g/transportfever3/m/vehicle-comparison) は、置き換え前にモデルを比較するのに役立つ。
