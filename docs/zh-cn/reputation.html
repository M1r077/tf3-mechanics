城镇声誉

什么会降低城镇的声誉评价，它恢复得多快，庆典和营销活动实际做了什么，以及为什么切断两座城镇之间的道路代价这么大。

声誉是城镇窗口六项评价之一，城镇当局取其中最低的一项（见城镇增长）。声誉从 100 % 开始，只会因为你建造或失败的事情而下降：地形工程、移除树木和石头、拆除城镇建筑、失败的补贴，以及被切断的主要连接。时间、庆典和营销活动会让它回升。

1什么会降低声誉

你确认的每次建造都会在执行前检查；损失记在相关城镇上（towns.script.tl:271-291，town_util.tl:1062-1080）。只有你自己的建造才算，地图编辑器中什么都不算（town_util.tl:1078-1080，towns.script.tl:233，towns.script.tl:271）。

  • 建造时提示框显示声誉：-x %，涉及多座城镇时还会显示数量（construction_react_util.tl:3818-3864）。它按满分评价计算。

2被切断的主要连接

当游戏提示城镇之间的道路连接已中断或城镇之间的旅行时间过长时，主要连接就算被切断（town_util.tl:378-380，town_warning.script.tl:7-22）。每座相关的其他城镇扣 1/3，评价会立刻显示出来（town_util.tl:401-403）：

被切断的连接 声誉最多 评价 来源
1 67 % 非常好 town_util.tl:983-985
2 33 % 中等 town_util.tl:983-985
3 0 % 非常贫穷：城镇停止增长 town_util.tl:607-633
  • 切断期间，惩罚也会在 3 个月内一步步写进保存的分数（towns.script.tl:137-145）。修好道路后，这部分只按正常速度恢复：长时间切断会在之后一段时间里继续拖累声誉。
  • 67 % 正好在“非常好”的边界上：再有任何小损失，城镇就会降到“好”。

提示

先建新路，再拆旧路。 每条被切断的主要连接会立刻扣掉三分之一的声望，切断越久，恢复也越久。

3声誉如何恢复

  • 自动恢复：每 3 个月游戏时间（360 秒）恢复一级（1/6），营销活动期间每个月（120 秒）一级（towns.script.tl:121-135）。日历速度 ×1 时约为每年 67 %，活动期间 200 %：从 0 % 回满约需 1.5 年。城镇窗口中的年度声誉恢复 33 % 和 100 % 是固定文字，只有实际速度的一半（town_react_util.tl:1066）。在测试城镇实测：每 358 秒一级，活动期间每 120 秒一级。
  • 恢复会把增加量分到所有原因上；不会超过仍未修复的切断连接（town_util.tl:1649-1687）。
  • 庆典：城镇里第一位乘客登上你的线路 +50 %，第一批货物送到城镇 +50 %，城镇每次升级 +50 %，每个工业第一次收到货物时最近的城镇 +20 %（celebrations.script.tl:181-273）。这时消息末尾会加上定居点声誉已提升。或你在…的声誉有所提升。（celebration_react_util.tl:63-75）。只有声誉低于被切断的主要连接仍允许的上限（满分减去每条切断连接 1/3）且声誉设置为打开时才算，战役任务中不算（celebrations.script.tl:79-93，celebrations.script.tl:140-142）。
  • 供给城镇接受时随机给予现金预付或 +5 % 到 +20 % × 风险系数（deliver_cargo_town.script.tl:197-200，deliver_cargo_town.script.tl:220-222）。和所有增加一样，它只抵消已有的损失（towns.script.tl:324-330）。

脚本按每级 360 秒游戏时间计算（活动期间 120 秒），一个月为 30 天、每天 4 秒。恢复按游戏时间进行：日历越慢，日历上的一年越长，每个显示年份恢复得越多。线路成本减半能把多少居民吸引到你的线路上，由引擎的路线选择决定。

5须知

  • 留意建造提示框：如果显示声誉：-x %，隧道或更平缓的线路往往比声誉更划算。
  • 不要让两座城镇之间的主要道路一直断着：每条立刻 −33 %，三条会让城镇停下。
  • 声誉满分时的营销活动只帮助你的线路，不提升评价。在大工程刚结束、恢复还有东西可补时再开展。
  • 总部大型模块的声誉恢复奖励（+1 %）会显示在奖励标签页中，但在脚本里它只改变一个没有任何评价读取的数值（hq_module_l.module.lua:171，towns.script.tl:157，town_util.tl:829，town_util.tl:857）。
  • 成就不是我的错需要一座城镇的声誉降到 1 % 以下（achievements.script.tl:261-267）。
