Настройки отправления: полная загрузка, Уровень заполнения и время стоянки

Когда транспорт покидает остановку: три режима отправления, Уровень заполнения для каждого груза и минимальное, максимальное и дополнительное время стоянки.

Проверено в скриптахОфициальная викиОбновлено 2026-11-15Версия игры 40425
600 sМакс. время стоянки по умолчанию для новой остановки
30 s / 60 sМакс. дополнительное ожидание по умолчанию, дорога / железная дорога
0–100 %Уровень заполнения для каждого груза, от вместимости транспорта

У каждой остановки линии свои настройки отправления. Они находятся в окне «Фильтр грузов» остановки (нажмите на остановку в окне линии). Они решают, сколько транспорт там грузит и как долго он может ждать.

1Настройки

Настройка Значения Новая остановка Источник
«Грузить по возможности», «Полная загрузка (любой тип)», «Полная загрузка (все)» один из трёх Грузить по возможности (измерено) cargofilter_window.tl:798-821
«Мин. время стоянки» 0–600 с, шаг 10 0 с (измерено) cargofilter_window.tl:841-845
«Макс. время стоянки» 0–600 с или «---» (без ограничения, ползунок в конце) 600 с (измерено) cargofilter_window.tl:855-863
«Макс. дополнительное ожидание» 0–600 с, шаг 10 60 с; 30 с на автомобильной или трамвайной станции без железной дороги cargofilter_window.tl:827-831, line_util.tl:478-490
«Уровень заполнения» для каждого загружаемого груза 0–100 %, шаг 1 100 % cargofilter_window.tl:698-704, line_util.tl:472
  • Щелчок по времени открывает поле для числа: там можно ввести значения больше 600 с (cargofilter_window.tl:204-208).
  • Три времени держат порядок между собой: если поднять минимум или дополнительное ожидание выше максимума, максимум тоже поднимается (cargofilter_window.tl:834-836, cargofilter_window.tl:848-850); если опустить максимум, два других тоже опускаются (cargofilter_window.tl:865-869). Пока максимум равен «---», ничего не подстраивается.
  • Изменение любого из них помечает линию как настроенную: автоматическая настройка больше не трогает её списки Загрузка (cargofilter_window.tl:438, см. Скорость погрузки и разгрузки). Сама автоматическая настройка никогда не меняет режим и время, но сбрасывает каждый Уровень заполнения на 100 % (line_util.tl:495-719, line_util.tl:511, line_util.tl:543).

2Уровень заполнения: предел для каждого груза

Уровень заполнения — это наибольшее количество этого груза, которое транспорт берёт на этой остановке, как доля вместимости транспорта, округлённая до ближайшей единицы (измерено в игре).

Транспорт Уровень заполнения Уезжает с
грузовик, 15 мест, бревна 50 % 8 (7,5 округлено вверх)
грузовик, 22 места, ткань 70 % 15 каждый раз (15,4)
поезд, 18 мест, стекло 48 % не больше 9 (8,64)
трамвай, 28 мест, топливо 66 % не больше 18 (18,48)
  • Груз, который уже на борту, учитывается: трамвай, приехавший с 14 топлива, уехал с 18, а не с 14 + 18.
  • Выше предела ничего не грузится и ничего не выгружается из-за него: грузовик, приехавший с 22 удобрений (предел 11), уехал с 22.
  • 0 % означает: не грузить этот груз здесь.
  • В режиме полной загрузки предел считается полной загрузкой: грузовики с бревнами с Уровнем заполнения 50 % ждали около 270 с и уехали с 8 из 15, а не с 15.
  • Процента выгрузки нет. Выгрузку решают список Загрузка и «Принудительно выгружать весь груз по прибытии» (Скорость погрузки и разгрузки).

3Полная загрузка и время стоянки

  • Грузить по возможности: транспорт берёт то, что есть, и уезжает.
  • Полная загрузка (все): транспорт ждёт, пока не заполнится. Грузовики с бревнами ждали 460–566 с и уехали с 15 из 15.
  • Полная загрузка (любой тип): транспорт уезжает, когда заполнен один груз. Поезд с бревнами и досками уехал со 143 и 144 бревнами через 369–380 с; два других отправления примерно через 30 с с 57 и 118 бревнами не объяснены.
  • Макс. время стоянки заканчивает ожидание, даже если ничего не загружено. Поезд с овощами в режиме «Полная загрузка (все)» с максимумом 120 с либо заполнялся (64 из 64) примерно за 25 с, либо уезжал через 116–120 с с 26 или 0. С максимумом по умолчанию 600 с он уехал с 26 из 64 через 596–600 с.
  • Мин. время стоянки — это вся стоянка вместе с погрузкой, а не дополнительное время после неё: при 60 с поезда со стеклом стояли 55–61 с каждый раз, сколько бы они ни загрузили.
  • Макс. дополнительное ожидание: «Maximum wait time after loading to improve vehicle distribution» (cargofilter_window.tl:828). Пока транспорт ждёт отправления по расписанию, окно транспорта показывает «Сохраняет безопасную дистанцию» (entity_window_util.tl:2283-2284), предположительно во время этого ожидания.
  • Несколько транспортных средств на одной остановке грузятся одновременно, когда бы каждое ни приехало (видно в игре). Два грузовика с бревнами, приехавшие с разницей около 90 с, уехали в одну и ту же секунду, каждый с 8. Как груз делится между ними, не измерялось.

Скрипты только хранят настройки; когда транспорт уезжает, решает движок.

4Полезно знать

  • Долгое ожидание с полной загрузкой на остановке, куда приходит мало груза, блокирует платформу: другой транспорт линии встаёт в очередь за ним.
  • Короткое Макс. время стоянки с полной загрузкой может отправлять транспорт пустым, если он возвращается раньше, чем появится новый груз.
  • Однажды поезд в режиме «Полная загрузка (все)» стоял 783–992 с при максимуме 600 с. Причина не найдена.

Скрипты игры

Три режима отправления, Мин. / Макс. время стоянки 0–600 с (или без ограничения), Макс. дополнительное ожидание 0–600 с (60 с, 30 с на дороге), Уровень заполнения 0–100 % для каждого груза; измерено: Уровень заполнения ограничивает груз на борту, округляется до ближайшей единицы и считается полной загрузкой; Макс. время стоянки заканчивает полную загрузку, даже пустую; Мин. время стоянки включает погрузку; транспорт на одной остановке грузится вместе.

Пути указаны внутри папки игры base/content или её zip-файлов.
