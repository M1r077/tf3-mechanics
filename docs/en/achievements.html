Achievements

What the game script checks for each Free Game achievement and when, which ones count only base-game vehicles, cargo and animals, and which checks are left to the engine.

The official wiki lists 41 achievements. The game script (achievements.script.tl) unlocks 17 of them itself and feeds 9 cross-game counters; the others (campaign, weather, town size, warehouse, interest, boosters, cars, 1900-2000, steam in the 2000s) are checked elsewhere, by the engine or the platform. Every check first asks the engine whether the achievement can still be unlocked; whether mods or settings block it is decided there (achievements.script.tl:632, achievements.script.tl:510).

Tip

Summit Stopover checks the height of the first wagon when the train stops, not the height of the station building. Build the station on a mountain above 500 m and run one train there.

Decided by the game engineC++, not visible in the scripts

Whether an achievement can still be unlocked (isAchievementUnlockable), whether the counters are switched off (areStatsDisabled), the targets of each counter and the 24 achievements not in the script are handled by the engine and the platform. The official wiki says achievements are generally unavailable with non-cosmetic mods or with gameplay settings away from the standard values.

3Mods and achievements

Using mods does not switch achievements off by itself. Two things decide it: whether each active mod is marked cosmetic, and whether the gameplay settings stay at the standard values.

  • Every mod has a cosmetic flag in its mod.json. The game's own API documentation (folder api/tealdef, field ModDesc.cosmetic) says: "If the mod is purely cosmetic, cosmetic mods still allow achievement from being earned while playing".
  • The official DLCs and campaign missions are mods too, and all of them are marked cosmetic (dlcs/*/mod.json, mods/release/urbangames_campaign*/mod.json).
  • In the new game page and in the load game page, the game asks whether the list of active mods still allows achievements (new_game_or_map_settings_page.tl:902-903, savegame_react_util.tl:1063-1064). If not, a yellow label next to the difficulty says "Achievements cannot be earned." (savegame_react_util.tl:1485-1496).
  • Each savegame also keeps its own flag (achievementsEarnable). If it is off, the load page shows this yellow label too, whatever mods you pick now (savegame_react_util.tl:1035-1037). Only a mod that forces achievements back on is checked again (savegame_react_util.tl:1063).
  • The gameplay settings (difficulty and the other game parameters) are a second reason: with values away from the standard ones the difficulty shows as Custom (difficulty_util.tl:201-229) and, per the official wiki, achievements are unavailable.

So a game with only cosmetic mods and standard settings can still earn achievements. One non-cosmetic mod, or settings away from the standard values, is enough to block them, and a savegame that was blocked once stays blocked.

Decided by the game engineC++, not visible in the scripts

Which settings exactly count as "away from the standard values", and when the savegame flag is set, is decided by the engine: not in the readable files.

Tip

The game's own rule is clear: achievements only mean something when everyone plays by the same rules; otherwise, what's the point? An achievement earned with the rules bent isn't really an achievement. The scripts block them as soon as a non-cosmetic mod is active, and keep a savegame blocked once it was. You don't need to check each mod: if the yellow label next to the difficulty is shown, achievements are off; if it isn't, they count. A good way to play: earn the achievements with the standard settings and cosmetic mods only, and use separate free or sandbox games for gameplay mods and custom settings.

4Good to know

  • Each "first time" achievement is checked against the previous check: it needs a new event in a game where the achievement is still open, an old subsidy or rank from a save does not count again (achievements.script.tl:633, achievements.script.tl:779).
  • Your rank, subsidies and Reputation are explained in Company rank, perks and headquarters, Subsidies and Reputation.

Official wiki vs game scripts

Adds detail
Official wiki says

"There are 41 achievements that can be earned by completing a certain task or reaching a specific goal." "Achievements are generally unavailable if non-cosmetic mods are used or the gameplay settings are deviating from standard values." (Achievements)

Game scripts show

17 achievements and 9 counters are in the script. It refines the official texts: Caretaker means the delivery rating reaching Excellent, It Wasn't Me a Reputation below 1 %, Summit Stopover the first wagon above 500 m, Perfectionist demolish-rebuild-demolish-rebuild of the same station, and Heritage Fleet all base-game ship models on lines at once. Only base-game vehicles, cargo and animals count for the counters.

Paths are inside the game's base/content folder or its zip files.
